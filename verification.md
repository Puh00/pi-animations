# Verification

Verified on `refactor/animation-interface` with Node 22.23.2 and Pi 1.3.0. The changes add a shared `Animation` interface and registry under `animations/`. The generic player owns frame timing, terminal formatting, responsive layout, caching, and timer disposal. `index.ts` uses the registry for Pi integration. Aurora's renderer remains unchanged in behavior and passes its pinned fixtures.

## Aurora fixtures

`testdata/aurora-reference.json` contains 27 frames generated by the original Aurora implementation at upstream commit `b2b26045b38aa4f59dd50781640cac65e9a291c1`. Cases cover 4 by 3, 40 by 8, and 60 by 10 cells; seeds 1, 7, and 42; and ticks 0, 30, and 90 at 24 frames per second. `test/aurora.test.mjs` compares every glyph and foreground/background RGB value exactly. All 27 pass. The parent agent independently regenerated the fixtures with Go 1.26.3 and confirmed a byte-for-byte match.

To regenerate them, copy `testdata/aurora-reference.go` into the pinned upstream checkout at `cmd/aurora-fixture.go`, run `go run ./cmd/aurora-fixture.go`, and redirect the output to this repository's `testdata/aurora-reference.json`. Go is not needed to run the package.

The player uses Pi's color conversion and retains ASCII brightness shading for colored cells when `NO_COLOR` is set. These terminal fallbacks are outside the truecolor fixture comparison.

## Rendering cost

`npm run bench` measured 120 frames per width after warming the renderer. It includes terminal color formatting and excludes Pi screen diffing, terminal output, and network transport. Results from Node 22.23.2 on this host:

- 60 columns by 10 rows: 0.32 ms median, 0.54 ms p95.
- 120 columns by 10 rows: 0.63 ms median, 1.05 ms p95.
- 240 columns by 10 rows: 1.22 ms median, 1.72 ms p95.
- 320 columns by 10 rows: 1.58 ms median, 2.19 ms p95.

Cached render median was about 0.0001 ms at each width. These are local CPU measurements, not whole-Pi or terminal throughput measurements.

Not checked: other Pi versions, Windows terminals, light-theme visual contrast, or Pi's automatic retry and compaction paths in a live model session.
